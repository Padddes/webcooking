# paddes.lu

Source for **paddes.lu**: a personal project hub with a Path of Exile 1 learning section (`/poe`) and a map regex builder.

## Requirements

Node.js 22.18 or newer. There are no npm packages to install.

## Commands

```sh
npm run dev      # build and preview at http://localhost:4321/
npm run build    # build into dist/
npm test         # build and run all tests
```
